# ADR-0036：開場畫面、主題曲與重新開始

- 狀態：已採用
- 日期：2026-11-17

## 背景

打開遊戲直接落在地圖上：沒有一個畫面告訴玩家這是什麼遊戲，也沒有屬於遊戲自己的曲子。瀏覽器又要等使用者點過一下才肯出聲，所以第一個聲音常常是孩子已經在點地圖時才出現。

一般遊戲的開場畫面有「新遊戲」和「繼續」。這個遊戲只有一份存在裝置上的進度，「新遊戲」放在孩子點得到的地方，一按就把進度洗掉。

## 決策

- **每次造訪先看到開場畫面**：遊戲名稱、站在紅瓦屋頂上的那一對西薩（點了會說名字）、一顆主要按鈕
  - 標誌是五塊積木拼成的「西薩搭搭路」，一塊一塊掉下來，顏色是遊戲裡積木的顏色
  - 背景是玩家正要去的那一區的白天場景（新玩家是那霸），玩到哪裡，開場畫面就換成哪裡
  - 屋頂下面是房子的牆，一路延伸到畫面底部；主要按鈕在牆上，橘色按鈕在米白牆上看得清楚
- **一個存檔，一顆按鈕**：看過開場故事的玩家是「繼續」，下面一行寫旅程走到哪裡（「下一站：美國村」或「那霸市 第 2 / 5 站」）；新玩家是「開始」
  - 新玩家按「開始」之後，才請大人選誰在玩、再播開場故事，開場畫面上不跳出任何視窗
- **一次造訪只出現一次**：按過之後記在 `sessionStorage`，同一個分頁重新整理（包括接受新版本）直接回地圖；關掉再打開、加到主畫面的 App 重新啟動，才會再看到
- **主題曲〈西薩搭搭路〉**：原創，琉球音階，116 BPM、16 小節，輕快的打擊節奏。開頭「短短短短長」的樂句就是「西－薩－搭－搭－路」，前後半段的結尾再出現一次。它排在配樂佇列（ADR-0035）的第一首，在開場畫面響起、接著帶進地圖
- **能自動播就自動播**：開場畫面一出現就試著啟動聲音。瀏覽器允許時（多半是加到 Android 主畫面的 App）主題曲馬上響；不允許時（iPhone、iPad 一律不允許）照舊等第一次點擊
- **重新開始放在大人設定**：要按住 1.5 秒才打得開的大人設定裡，「重新開始」先再問一次，寫出會清掉的進度（收集幾隻、福氣幣幾枚、走完幾區），旁邊就是「先備份」；確定後清掉進度、只留聲音與音樂的開關，回到開場畫面，下一個玩家從選年齡開始

### 考慮過、沒採用

- **開場畫面上放「新遊戲」**：孩子一按就清掉進度
- **三個存檔欄位**（兄弟姊妹各一份）：比較完整，但要改存檔結構、備份碼和年齡設定，先做單一存檔
- **先一張「點一下開始」的畫面，再進開場畫面**：只為了讓主題曲在開場畫面就響，多按一次；改成主題曲排在佇列第一首，按下去之後接著在地圖上播

## 影響

- `Screen` 多了 `title`；`enterGame` 從開場畫面進地圖，新玩家在這之後才被問年齡、看故事；`startOver` 清掉進度回到開場畫面
- 端對端測試的 fixture 預設跳過開場畫面（和重新整理一樣），測開場畫面的測試設 `window.keepTitle`
- 開場畫面與標誌用的字已重建字型子集
