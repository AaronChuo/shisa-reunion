# ADR-0021：旁白與西薩的聲音用 Azure 台灣國語語音預先錄好

- 狀態：已採用
- 日期：2026-10-19

## 背景

「念給我聽」、開場故事和西薩說話，原本都用裝置內建的語音（ADR-0007、ADR-0010）。不同裝置的音色差很多，有些 Android 沒有台灣口音；西薩的聲音也只是把裝置語音調高，聽起來不像角色。兩份 ADR 都預告之後換成 Azure 語音。

## 決策

- **聲音**（試聽過 Azure 全部三個台灣國語聲音，以及兩個支援台灣國語的兒童聲音後選定）
  - 旁白：曉臻（`zh-TW-HsiaoChenNeural`）原本的音調
  - 西薩：同一個聲音，音調調高 30%、速度快 10%
- **預先錄好，不在遊戲裡即時合成**：`pnpm voice`（`scripts/voice.mjs`）在本機把每一句要念的話錄成 MP3，放在 `public/voice/`，跟著 PWA 預先快取，離線也能聽
  - 要念的句子集中在 `src/audio/voiceLines.ts`：開場故事、西薩的三句話、新積木和機關的說明、「西薩是什麼？」、60 隻西薩的故事、11 張明信片，共 95 句
  - 檔名是「說什麼＋怎麼說」的雜湊（`voiceKey`），所以只會重錄新增或改過的句子，用不到的會刪掉；清單寫在 `src/audio/voices.json`
  - 單元測試擋下沒錄到的句子（改了文字忘了跑 `pnpm voice`），也檢查清單和檔案一致
  - 金鑰只放在本機的 `.env.local`（`AZURE_SPEECH_KEY`、`AZURE_SPEECH_REGION`，見 `.env.example`）；音檔進 repo，所以 CI 和部署都不需要金鑰
  - 格式：MP3、24 kHz、48 kbps、單聲道，各瀏覽器都能播
- **播放**：用遊戲本來的 Web Audio（和音效同一個 AudioContext），直接送到喇叭，不經過殘響，也不受音效、音樂開關影響；朗讀時背景音樂壓低
  - 用 fetch 加 `decodeAudioData` 播放，service worker 直接回快取，不會遇到 `<audio>` 的 Range 請求問題
  - 退回裝置語音的情況：句子沒有錄音、遊戲音訊叫不醒（還沒碰過螢幕）、或音檔載入失敗
  - iPhone、iPad 的網頁音訊要在點擊後才醒，而且要一點時間（回到 App 後也一樣）。有錄音的句子先等它醒，最多半秒，等不到才用裝置語音（v0.20.1）
  - 音效和音樂都關掉時，「念給我聽」仍然播錄音
  - 解碼後的音檔一秒約佔 100 KB 記憶體，只保留最近播過的 6 段，避免孩子聽完 60 個故事後記憶體一直長
- **授權與揭露**
  - 微軟產品條款只把「合成的音檔可以商用」明文給付費層（S0）。v0.20 這一批是用免費層（F0）錄的，目前是家庭、非商業使用；之後的版本把資源切到 S0 再整批重錄（刪掉 `public/voice/` 後跑 `pnpm voice`，95 句約 5,100 字，不到 1 美元），商業化前一定要做（#15）
  - 微軟的 AI 行為準則要求揭露合成語音：圖鑑的「照片來源」改名為「素材來源」，加一行說明旁白和西薩的聲音是 Azure AI 合成的

## 影響

- 離線包從約 2.2 MB 變成約 8.8 MB（95 句約 19 分鐘的語音，6.6 MB）。第一次開啟時在背景下載，不影響開始玩；但要全部下載完才能離線玩，網路慢時這段時間會變長。之後的更新只下載有變的檔案，沒改的錄音不會重新下載
- 改了任何會念出來的文字，要在有金鑰的電腦上跑 `pnpm voice` 再 commit
- e2e：故事朗讀改成檢查有載入錄音；另一個測試擋掉錄音，確認退回裝置語音時只念中文音譯

## 替代方案

- **遊戲裡即時呼叫 Azure**：要網路、金鑰會進到前端，離線不能用，不採用
- **真人錄音**：最好聽，但每次改字都要重錄，之後若要上架可以再考慮
- **Opus 格式**：檔案小一半，但 iPhone、iPad 要 iOS 18.4 才完整支援，先用 MP3
