# ADR-0001：用 React + Vite + TypeScript 重構

- 狀態：已採用
- 日期：2026-10-15

## 背景

原型 v0.1／v0.2 是單一 HTML 檔，約 1,500 行，用字串拼 SVG 和 DOM。玩法已經驗證過了，接下來畫面會越來越多（扭蛋、圖鑑、家長功能、關卡編輯器），狀態也越來越複雜（旅程、收集、設定）。單一檔案已經難以維護和測試。

## 決策

- **React 19 + Vite 8 + TypeScript 7**：畫面拆成元件，美術改成 SVG 元件（積木、風獅爺、機關）
- **Zustand 5** 管狀態：搭配 `persist` 把進度存到 localStorage，搭配 `immer` 寫巢狀更新。一個 store 分成 `progress`（會存檔）和 `ui`（暫時狀態）
- 遊戲流程集中在 `game/actions.ts`，元件只負責顯示和呼叫動作
- **Biome 2** 同時負責 lint 和 format，設定只有一個檔案
- **pnpm 10**

## 影響

- 規則、內容、畫面分層，各自可以測試
- 跟平常工作用的生態一致，維護成本低
- React 的執行時期約 100 KB（gzip 後），但 PWA 會快取在裝置上，對載入速度影響很小
- 存檔格式有 `normalizeProgress` 修正機制，舊存檔欄位缺漏時也能讀

## 替代方案

- **Preact**：體積小，API 幾乎一樣，但部分 React 生態套件要另外處理相容
- **不用框架的原生 TS 模組**：改動最少，但畫面一多，狀態和畫面同步要自己處理
- **遊戲引擎（Phaser、PixiJS）**：適合大量精靈動畫，但這款遊戲是回合制、以 UI 為主，用 SVG 與 DOM 已經足夠，引擎反而增加學習與包裝成本
