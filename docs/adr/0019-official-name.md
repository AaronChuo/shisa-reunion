# ADR-0019：正式名稱「西薩搭搭路」

- 狀態：已採用
- 日期：2026-10-19

## 背景

v0.3 起畫面與安裝名稱暫用「小獅搭路」，repo 暫名 `shisa-reunion`（取「兩隻獅子重逢」）。v0.9 起主角一律叫「西薩」（ADR-0010），當時留了一個問題：正式命名時要不要把「西薩」放進名字。

## 決策

- **遊戲名稱「西薩搭搭路」**
  - 主角的名字直接放進遊戲名，孩子在開場故事學到的「西薩」就是遊戲的名字
  - 「搭搭路」用疊字，念起來像兒語、好記，也直接說出玩法：用積木搭一條路
- **改的地方**：主畫面標題、安裝名稱（manifest 的 `name`、`short_name`，iOS 的 `apple-mobile-web-app-title`）、網頁標題、圖示的 SVG 標題、README 與文件
- **不改的地方**：repo `AaronChuo/shisa-reunion`、網址 `shisa-reunion.vercel.app`、存檔的 localStorage 鍵 `shisa-reunion`
  - 進度存在網址對應的瀏覽器儲存空間。換網址等於換一個網站，已經加到主畫面的裝置會留在舊網址，進度也帶不過去
  - repo 名稱和存檔鍵玩家看不到，不值得冒丟進度的風險
- 英文名稱還沒定。標誌、網址仍用 Shisa（ADR-0010），需要英文名時再決定

## 商標查核（2026-10-19，不是法律意見）

- 智慧局商標檢索：「西薩搭搭路」「搭搭路」沒有相同的註冊或申請案；App Store、Google Play 也沒有同名或近似的 app
- **但「西薩Siza」已註冊**：台豐興業股份有限公司，第 35、41、43 類，2021-01-16 註冊、到 2031-01-15。第 41 類（註冊號 02116609）的服務包含「提供線上遊戲服務（由電腦網路）」
- 現在是家庭、非商業使用，不屬於商標法上「為行銷之目的」的使用（商標法第 5 條），沒有問題
- 商業化前要請商標代理人評估：「西薩」放在名稱開頭，可能被看成主要識別的部分。可能的做法：查對方是否實際在第 41 類使用（連續三年未使用可申請廢止，商標法第 63 條）、取得併存同意，或改名讓「西薩」只當角色名
- Camelot Jr. 在台灣的中文名是「飛躍城堡歷險記」，和「西薩搭搭路」沒有共同的字或概念
- 香港、中國、日本的商標庫需要互動驗證，這次沒查，列在商業化前檢查清單（#15）

## 影響

- Android 用 Chrome 安裝的，Chrome 檢查到 manifest 更新後會換成新名字（可能先問一次）；iPhone、iPad 主畫面上的名字是加入當下決定的，會維持「小獅搭路」
- iPhone、iPad 的主畫面網頁 App 有自己的資料，刪掉圖示可能連進度一起刪掉。所以不要為了換名字而刪掉重加，等進度匯出／匯入（#9）做好再說
- 商業化前要做商標檢索與註冊（#15）
