# ADR-0009：可以用手操作的扭蛋機

- 狀態：已採用
- 日期：2026-10-16

## 背景

v0.6 的扭蛋機按一下就自動跑完投幣、轉動、掉落的動畫。孩子想像真的扭蛋機那樣自己投幣、自己轉把手，也想看到玻璃罩裡的扭蛋真的會滾、會撞，掉出一顆時其他顆會跟著滾下來。

## 決策

- **投幣**：把福氣幣從機台右邊的錢幣堆拖進投幣口；點一下錢幣堆、投幣口或主要按鈕也行。投進去時「叮」一聲，把手亮起來
- **轉把手**：手指按住把手轉圈，跟真的棘輪一樣只能順時針轉，倒轉只會打滑；每轉 90 度「喀」一聲，轉滿一圈掉出一顆。點一下把手轉 90 度；主要按鈕「轉一圈」會自動轉完，給還不會畫圈的孩子用
- **沒投幣轉不動**：把手會晃一下，發出「轉不動」的聲音
- **福氣幣在扭蛋真的掉出來時才扣**；投了幣沒轉就離開或換台，幣會退回
- **玻璃罩裡的扭蛋是真的數量**：這台還有幾隻沒抽到就有幾顆，抽完就空了；換台時重新倒進去
- **物理**（`src/gacha/physics.ts`，自己寫的小型 2D 模擬，沒有用套件）
  - 圓形扭蛋在圓形玻璃罩裡：重力、彼此碰撞、撞玻璃反彈，接觸點的摩擦讓扭蛋邊滑邊滾
  - 固定步長 1/120 秒、每步 4 次碰撞修正；很慢的碰撞不反彈，靜止的扭蛋視為被靜摩擦卡住，所以堆起來能真的停下來
  - 全部靜止後動畫迴圈停掉，不耗電；有人轉把手或掉出扭蛋時再醒來
  - 轉把手時底下的攪拌器把扭蛋往上踢，越靠下、轉越快踢得越大；轉滿一圈，最下面那顆從出口掉下去，其他顆自己滾下來補位
  - 撞擊夠大時發出輕輕的「喀啦」，限制頻率不會吵
- **抽到誰仍由原本的規則決定**（不重複、稀有比較難抽）。扭蛋殼的顏色只是外觀、跟內容無關，跟真的扭蛋機一樣；物理只決定「哪一顆掉出來」，不影響機率
- **給孩子的提示**：閒置時機台自己出手指，依步驟示範把錢幣拖到投幣口、繞著把手轉圈、點出口的扭蛋；主要按鈕在這個畫面不再另外出手指，畫面上永遠只有一隻手指

## 影響

- 扭蛋流程從一個 `pull()` 拆成 `insertCoin` → `releaseCapsule` → `capsuleOut` → `openCapsule`
- 揭曉視窗的扭蛋殼用實際掉出那顆的顏色
- 物理有單元測試（會停下、不重疊、會滾、掉一顆後其他顆往下補）；端對端測試用滑鼠實際拖幣、畫圈轉把手、倒轉不會掉
- ADR-0008 的「點扭蛋機本體就能轉」由這份取代
