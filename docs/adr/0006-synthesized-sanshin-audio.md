# ADR-0006：三線音色用程式即時合成，背景音樂選用沖繩傳統民謠

- 狀態：已採用
- 日期：2026-10-16

## 背景

v0.3 的音效是簡單的電子嗶聲，也沒有背景音樂。我們希望遊戲聽起來有沖繩味：音效用三線、太鼓、三板，背景音樂用三線彈的曲子，不同場景播不同曲子。這款遊戲要能離線玩，也要避開錄音和樂曲的版權問題。

## 決策

- **三線音色用 Karplus-Strong 物理模型即時合成**（`src/audio/ks.ts`）
  - 一段雜訊在延遲線裡循環，迴圈中的低通濾波讓高頻先消失，聽起來就像撥弦
  - 延遲用整數延遲加一階全通濾波處理小數部分，並扣除低通濾波器在該音基頻的精確相位延遲；單元測試確保每個音的誤差小於 3 音分
  - 撥弦位置用梳狀濾波；爪撥用 4 毫秒的高頻雜訊；蛇皮琴身用三段共鳴濾波加輕微失真
  - 兩種音色：音效用「傳統」（清脆），背景音樂用「柔和」（聽久不刺耳）
- **太鼓與三板也是合成的**：太鼓的鼓皮音高放在 110–300 Hz，手機喇叭才播得出來
- **兩條音軌**：音效和背景音樂各有開關；過關音效響起時背景音樂自動壓低；換曲時先淡出再淡入
- **曲目**
  - 四首沖繩傳統民謠，作者不詳，屬於公共財：〈てぃんさぐぬ花〉、〈赤田首里殿內〉、〈谷茶前〉、〈安里屋ユンタ〉（大家熟悉的版本由宮良長包 1934 年改編，他 1939 年過世，旋律已是公共財；歌詞不用）
  - 旋律取自 mu-tech.org 免費 MIDI 的主旋律聲部，只讀取旋律，不使用他們的編曲或檔案
  - 兩首原創曲〈島風〉、〈搭路小調〉，只用琉球音階
- **場景配樂**：地圖〈島風〉、那霸港〈てぃんさぐぬ花〉、讀谷村〈谷茶前〉、美麗海〈安里屋ユンタ〉、首里城〈赤田首里殿內〉、扭蛋機與圖鑑〈搭路小調〉。每區最後一站同一首曲子加快 8%，配艾薩太鼓節奏
- **v0.5 補充**：新增三首同樣是作者不詳的傳統民謠〈唐船ドーイ〉、〈デンサー節〉、〈花ぬ風車〉，取法相同。美麗海改播〈唐船ドーイ〉，〈安里屋ユンタ〉移到它的故鄉竹富島；古宇利島〈花ぬ風車〉、西表島〈デンサー節〉
- **v0.15 補充**：三個新分區
  - 宮古島〈豊年の歌〉（ほうねんぬあやぐ）：宮古的祈豐收歌，由古老的「あやぐ」而來，沒有具名作者，屬於公共財。旋律取自 mu-tech.org MIDI 的主旋律聲部，只取唱的旋律；宮古民謠現行的三線伴奏是 1950–60 年代才編的，不使用
  - 中城城跡〈石拱門〉、久米島〈白沙洲〉：兩首原創曲，只用琉球音階。原本想用的傳統曲〈仲順流り〉（北中城村仲順的エイサー念佛歌）和〈久米阿嘉節〉都是作者不詳的傳統曲，但找不到可用的旋律來源，不憑印象採譜，所以先用原創曲；之後找到公有領域的樂譜再換
  - 刻意不用的：〈なりやまあやぐ〉通行版本是 1950–60 年代改作，改作者卒年查不到；〈中城情話〉1934 年作，作者 1986 年過世，仍在保護期
- **v0.18 補充**：逐首重新查證（JASRAC 作品資料庫、日文文獻）
  - 久米島改播傳統曲〈久米阿嘉節〉：久米島阿嘉村流傳的歌，1904 年的手抄工工四已經收錄，JASRAC 沒有任何具名的權利登錄。旋律取自大城彦五郎編《琉球楽典 工工四》下卷拾遺（1925 年印行，琉球大學附屬圖書館數位典藏），與明治期手抄本《工工四》（東京藝術大學附屬圖書館藏）57 拍逐格相同，可見編者沒有加入自己的創作。這是古典（野村流）的三線譜，不是聲樂譜；遊戲本來就用三線音色，照三線旋律合成。結尾補 3 拍休止湊成整小節，是編排，不是原譜。原創曲〈白沙洲〉退場
  - 〈仲順流り〉：旋律是公共財（JASRAC 登錄為「沖縄県民謡 P.D.」），但目前找得到的公有領域文獻都只有歌詞。喜納昌吉、新崎松秀、照屋政雄、新良幸人的版本登錄了補詞、補曲或編曲，要避開。可行的做法是從登錄為 P.D. 的錄音（例如嘉手苅林昌）聽寫主旋律，再用第二個錄音交叉確認；聽寫公共財的旋律、自己合成，沒有複製錄音本身。中城城跡暫時維持原創曲〈石拱門〉（#10）
  - 更正：〈デンサー節〉不是作者不詳，相傳是西表島上原村的役人宮良里賢 1768 年所作，早已是公共財；登川誠仁的〈新デンサー節〉是另一首仍受保護的歌
  - 其餘六首都查到 JASRAC 登錄為「沖縄県民謡 P.D.」；〈安里屋ユンタ〉通行的歌詞（星克作詞，保護到 2047 年）仍受保護，遊戲本來就不用歌詞
  - **mu-tech.org 的使用條款不允許商用**（MIDI 等檔案「商用の場合を除き」可當背景音樂）。遊戲只讀了公共財旋律的音符、沒有使用或散布他們的檔案，著作權上沒有問題；但商業化前，每首都用另一份獨立的公有領域來源重新核對並記下出處，或取得站長的書面同意（#15）。README 已加上 mu-tech.org 的連結致謝

## 影響

- 不需要任何音訊檔，PWA 離線也能播，套件只多幾 KB
- 第一次播放一個音時要先算出波形（每個音約數毫秒），之後快取
- 不能使用仍有著作權的近代沖繩歌曲，例如〈島唄〉、〈花〉、〈淚光閃閃〉、〈芭蕉布〉
- iPhone、iPad 開著靜音模式時，網頁本來就不會發出聲音，聲音設定面板有提醒

## 替代方案

- **真人錄音或取樣音色**：音色最真實，但檔案大、要處理錄音授權，離線快取的負擔也重
- **General MIDI 音源的 shamisen**：音色是日本三味線，不是沖繩三線，而且瀏覽器沒有內建 MIDI 音源
- **AudioWorklet 即時運算每個樣本**：更有彈性，但這裡預先算好每個音的波形再播放就足夠，相容性也較好
