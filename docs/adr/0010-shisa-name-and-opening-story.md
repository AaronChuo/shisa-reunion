# ADR-0010：主角叫「西薩」，用開場故事讓孩子認識牠

- 狀態：已採用（取代 ADR-0007 裡「畫面上叫風獅爺」的部分；西薩的聲音在 v0.20 換成預錄的 Azure 語音，見 [ADR-0021](0021-azure-narration.md)）
- 日期：2026-10-17

## 背景

v0.8 以前，畫面上同時出現「風獅爺」「獅子」「○○獅」，介紹頁又教「西薩」。孩子會被不同的叫法搞混。「風獅爺」其實是金門守護獅的名字，跟沖繩的不是同一個東西；而「西薩」對孩子是陌生的詞，要先教才會懂。

## 決策

- **遊戲裡一律叫「西薩」**，當作主角的名字和招牌
  - 每一隻叫「○○西薩」（素燒西薩、鯨鯊西薩、西表山貓西薩…），動物系列原本沒有「獅」字的也補上
  - 「獅子」只留在文化意義的地方：「沖繩話的獅子」、獅子舞、村落獅子／宮獅子／家獅子這類傳統分類
  - 「風獅爺」只在「西薩是什麼？」頁出現一次，介紹成金門的遠房親戚
  - 英文 Shisa 只用在標誌、網址、英文名；中文句子裡不夾英文，國語語音也念得順
- **開場故事「西薩的故事」**（`src/story/Opening.tsx`，文字在 `src/content/story.ts`）
  - 第一次打開時播放，五頁，每頁一張會動的圖、一兩句話、一個要孩子親手做的動作：點西薩聽牠說「我是西薩！」、撥一下吹起颱風
  - 同時教會遊戲規則：張嘴＝出發、閉嘴＝等待；颱風吹散；用積木搭路讓牠們團聚
  - 最後一頁「出發」直接進第一關，接上第一關的手指示範
  - 大人可以跳過；地圖上的「故事」按鈕可以重看
- **名字要常常聽到**：點地圖或關卡裡的西薩，牠用比較高、活潑的聲音說自己的名字；過關時喊「西薩團聚了！」。目前用裝置語音（音調調高），之後換成 Azure 語音或錄音
- iPhone、iPad 要有人碰過螢幕後才能自動發聲，所以第一次碰螢幕時先送一句空白語音解鎖

## 影響

- 遊戲名稱「小獅搭路」暫時保留，正式命名時再決定要不要把「西薩」放進名字（v0.18 定名「西薩搭搭路」，見 [ADR-0019](0019-official-name.md)）
- 端對端測試預設把故事標成看過（`e2e/fixtures.ts`，在測試自己的存檔之後才加上），專門測故事的檔案用原本的 Playwright
- 舊存檔第一次打開新版也會播一次故事，順便讓已經在玩的孩子認識新名字
