# ADR-0002：規則引擎寫成純函式，關卡在 Web Worker 產生

- 狀態：已採用
- 日期：2026-10-15

## 背景

遊戲的核心是三件事：

- **物理**：重力、重心平衡、什麼東西上面能疊
- **路徑**：走路、爬梯、彈跳、漲潮淹沒、石門開關
- **關卡產生**：隨機出題，再由求解器確認解得開，而且給的積木一塊都不能少

最難的四塊積木關，求解器要搜尋上千種擺法，在主執行緒跑會讓畫面卡頓。

## 決策

- `src/engine` 是不碰 DOM 的純 TypeScript：`pieces`、`grid`、`path`、`solver`、`generator`
- 隨機數用有種子的 mulberry32，**同一個種子一定產生同一關**
- 分區、岔路卡、各站設定放在 `src/content`，引擎不知道遊戲內容
- 關卡在 Web Worker 裡產生（`src/workers/generator.worker.ts`）。瀏覽器不支援 Worker 時，退回主執行緒
- 一直生不出關卡時，`relax()` 會逐步放寬條件（允許更多解法 → 拿掉「一定要爬梯／彈跳」→ 拿掉機關 → 少一塊積木），保證一定會產生出關卡

## 影響

- 引擎可以完整做單元測試，測試會跑過每個分區 × 每一站 × 每張岔路卡
- 同一套引擎之後可以直接重用在關卡編輯器、實體挑戰卡產生器、每日一題
- 旅程只存種子和關卡，問題可以重現

## 替代方案

- **預先產生固定題庫**：載入快，但缺少 roguelike 的隨機性，題庫也會被玩完
- **在主執行緒分段產生**：原型 v0.2 的做法，可行但要自己切時間片，程式比較複雜
