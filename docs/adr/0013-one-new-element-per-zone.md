# ADR-0013：每區一個新元素、隨機抽選、依等級解鎖

- 狀態：已採用
- 日期：2026-10-18

## 背景

孩子試玩和逐項審查後，發現三個問題：

- 機關太密：一區常同時出現好幾個新東西（美麗海一次教跳跳貝、石拱橋、漲潮），還沒熟就換下一個
- 岔路卡幾乎等於「選機關」，選擇沒有對價，也稀釋了核心樂趣。這個遊戲的核心是用積木搭路，機關只是另一個維度的變化
- 分區一個接一個開，之後要加更多分區時路線會太長、太死

## 決策

- **每區只帶一個新元素**（新積木或新機關），第一站教學；之後的站從「已經學過的元素」裡隨機抽
  - 那霸市（入門）不放任何元素，只練搭路
  - 目前的順序：讀谷村竹梯、美麗海海膽、古宇利島跳跳貝、竹富島星砂、西表島藤蔓、首里城石門
  - 漲潮、溜滑梯、石拱橋暫時不排，引擎保留，留給之後的新分區
- **「學過的」是指玩家走完過的分區**，而且只算同等級或更低等級的分區。同等級的分區可以自己選順序，所以不會碰到沒教過的東西；回頭重玩低等級分區也不會變難
- **第 2–4 站每站抽幾種**，依等級決定（`TIERS.counts`）：

  | 等級 | 0 種 | 1 種 | 2 種 | 3 種 |
  | --- | --- | --- | --- | --- |
  | 入門 | 100% | | | |
  | 初級 | 30% | 70% | | |
  | 進階 | 15% | 55% | 30% | |
  | 高手 | 10% | 45% | 45% | |
  | 大師 | | 30% | 50% | 20% |

  - 該區的新元素被抽中的機率是舊元素的 3 倍，且保證第 2–4 站至少兩站有它
  - 3 種只放在大師，6–7 格寬的地基放不下更多
- **最後一站**：新元素，加上依等級抽 0–2 種學過的元素（進階 1 種、高手 1–2 種、大師 2 種），積木和解法數也較嚴
- **整趟的安排在出發時就抽好**，存在旅程裡（`run.plan`），所以中途離開再回來也一樣
- **有些組合不同時出現**，因為生成太慢或生不出來：石門＋星砂、跳跳貝＋藤蔓；一站最多兩種特殊積木，有兩種時不再加機關
  - 單元測試會把每區所有可能的組合都生成一遍，確認元素都保留、不必靠放寬條件。新增元素或分區時，這個測試會指出要避開的組合
- **岔路暫時改成單張「下一站」卡**：顯示下一站有哪些元素（圖示）和積木數，點了就出發。岔路的新設計（例如只換風景的路線）另外決定
- **依等級解鎖**：走完入門開初級，走完初級一次開全部進階；之後每個等級走完「總數少一個」的分區（至少一個）就開下一級。舊存檔照通關紀錄重算，已經開的分區不會關掉
- 機關「石門機關」改名「石門」。首里真的有世界遺產「園比屋武御嶽石門」

## 影響

- 舊的 12 張岔路卡和它們的提示貝、海螺獎勵拿掉了；換題海螺只剩每趟一開始的 1 個
- 首里城第一站（石門教學）改成 2 塊積木：教學比較簡單，生成也從約 0.8 秒降到 0.03 秒
- 生成測試從「分區 × 站 × 岔路卡」改成「分區 × 所有可能的元素組合」，單元測試整體約 1 分鐘
- 抽選比例、權重、最後一站的組合之後會隨試玩調整，數字都集中在 `src/content/zones.ts`
