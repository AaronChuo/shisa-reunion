# ADR-0007：風獅爺文化小故事與「念給我聽」

- 狀態：已採用
- 日期：2026-10-16

## 背景

v0.5 把扭蛋擴充到 50 隻，每隻都以沖繩的一樣東西為題材（紅瓦、星砂、紅芋塔、大綱挽、西表山貓、琉球玻璃……）。我們希望孩子收集的同時也認識沖繩：大一點的孩子自己讀，小一點的由爸媽念。需要決定故事怎麼寫、怎麼朗讀，以及「風獅爺」這個叫法。

## 決策

- **每隻一段 50–75 字的小故事**，存在 `src/content/shisa.ts` 的 `story`
  - 講由來、典故或文化，一兩個具體事實就好，句子短、用孩子聽得懂的詞
  - 年份、數字、紀錄（例如富盛石獅 1689 年、塔可飯 1984 年金武町、那霸大綱挽 1995 年金氏紀錄）都查證過；沒把握的細節寫概括，不寫死
  - 涉及生態的題材順便帶一句愛護的做法（不打擾海龜、陸寄居蟹不帶回家、西表島開車要慢）
- **畫面上叫「風獅爺」**：台灣孩子最熟悉的說法（原指金門的守護獅）。圖鑑另有一頁「風獅爺是什麼？」，介紹沖繩叫「シーサー（西薩）」、就是沖繩話的「獅子」
- **日文詞一律附中文音譯**：「シーサー（西薩）」、「ゴーヤー（勾壓）」、「グルクン（古魯昆）」。爸媽不會日文也念得出來，單元測試擋下沒附音譯的日文
- **「念給我聽」用 Web Speech API**（`src/audio/speech.ts`）
  - 用裝置內建的國語語音，優先選台灣口音；iPhone、iPad、Android、Mac、Windows 都有，多數裝置不需網路
  - 朗讀前把「日文（音譯）」換成音譯本身，其餘假名拿掉，國語語音才不會亂念
  - 一句一句送出（有些引擎遇到長句會中斷），朗讀時背景音樂壓低，結束或關掉視窗就恢復
  - 裝置不支援就不顯示按鈕

## 替代方案

- **錄真人旁白**：最好聽，但 51 段錄音會讓離線包大很多，每次改字都要重錄；先不做，之後若要上架可再考慮
- **畫面直接叫「シーサー」**：比較道地，但孩子不會念、語音也念不出來，改成在介紹頁教

## 影響

- 中文字型子集從 494 字增加到 931 字，每個字重約 270 KB
- 不同裝置的語音音色不同，有些 Android 裝置沒有台灣口音時會用一般國語語音
- 存檔格式改成用分區 id 記錄通關與開放（原本是陣列索引），載入舊存檔時自動換算，原本開放的分區不會被鎖回去；美麗海走完過的存檔會直接打開新的古宇利島
