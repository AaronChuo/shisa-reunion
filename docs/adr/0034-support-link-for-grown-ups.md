# ADR-0034：贊助連結只放在大人設定

- 狀態：已採用
- 日期：2026-11-17

## 背景

遊戲免費、沒有廣告，也沒有任何收費。想給喜歡這個遊戲的大人一個支持的管道，但玩的人大多是孩子：一個點得到的外部連結，就可能把孩子帶出遊戲、帶到付款頁。

## 決策

- **只放在大人設定**：「聲音設定」裡按住 1.5 秒才打得開的大人設定，最下面一段「給大人的小角落」，說明遊戲免費、不向孩子收錢，按鈕「請小狂喝杯咖啡」
- **連到 Portaly 的贊助頁**，用瀏覽器另開分頁（`target="_blank"`），遊戲本身停在原地；離線時連不上，不影響遊戲
- **整個遊戲只有這一個對外連結**，端對端測試確認地圖上沒有
- **遊戲外**：GitHub repo 的 `.github/FUNDING.yml` 列出 Ko-fi 與 Portaly，repo 頁面會有 Sponsor 按鈕；README 最後一節也有。之後如果有介紹網站，放在頁尾
- **中文用 Portaly、英文用 Ko-fi**：Portaly 用新台幣、台灣常用的付款方式；之後有英文版時改連 Ko-fi（美元、海外信用卡與 PayPal）
- **不記錄點擊**：遊戲沒有造訪統計，這裡也不加

### 考慮過、沒採用

- **地圖或製作群頁放連結**：製作群頁在圖鑑裡，孩子點得到
- **過關或走完旅程時提一下**：打斷孩子，也像在跟孩子要錢
- **在遊戲裡直接收款或付費解鎖**：要後端與金流，也會讓遊戲變成商業用途

## 影響

- Vercel Hobby 限非商業用途（ADR-0004）。只放一個連到外部贊助頁的連結，站上不收款、不賣東西；Vercel 社群的回覆是單純請求贊助不算商業用途，正式條款以 Vercel 的 Fair Use Guidelines 為準
- 若之後改成收費、廣告或付費內容，先完成商業化前檢查清單（#15）
