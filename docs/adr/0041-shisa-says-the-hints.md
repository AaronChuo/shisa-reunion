# ADR-0041：西薩把闖關提示念出來

- 狀態：已採用
- 日期：2026-11-19
- 延續：[ADR-0008](0008-buttons-for-children-who-cannot-read.md)、[ADR-0040](0040-shisa-voice-by-gemini-voice-design.md)

## 背景

關卡裡的對話泡泡（「這站要用 3 塊積木」「把發亮的竹梯放到虛線那裡」「這樣會倒下來喔」）只有字。這個遊戲是做給還不識字的孩子玩的（ADR-0008），看不懂泡泡的孩子，只能靠大人念。西薩有了自己的聲音（ADR-0040）之後，泡泡可以由西薩說出來。

## 決策

- **關卡泡泡的每一句都預先錄好**：句子集中在 `content/hints.ts`，遊戲和錄音用同一份文字；`allHints()` 列出所有可能出現的句子，共 60 句
  - 每站開始：「這一站要用 1～4 塊積木」，有沒有星砂各一句；最後一站是 14 個終點的名字，有沒有星砂各一句
  - 第一站的示範：只錄起始那一對西薩的名字（新玩家第一次玩一定是這一對）
  - 提示：每種積木一句「把發亮的○○放到虛線那裡」，加上「先把發亮的這塊拿下來」「海水漲太高了……」
  - 機關：「石門打開了！」「海水漲上來了！」；放不下、會倒、壓著別的東西、固定的搬不動
  - 單元測試走過每一區、每一站，連生不出關卡時放寬的每一步，確認那站開始的句子都在清單裡
- **沒錄到的句子只顯示、不念**：不退回裝置語音，免得同一個角色突然換成另一個聲音
- **一站只說一次**：同一句在同一站只念第一次，之後只顯示，免得孩子一直放錯時一直聽到同一句。孩子按提示要的那句每次都念
- **泡泡消失就停**：放下積木、離開關卡時泡泡收起來，正在念的那句也停；過關時同樣停下，不和過關的音樂搶
- **跟著音效開關**：和西薩原本的三句一樣，音效關掉就不說；設定裡「音效」的說明加上「西薩說話」。「念給我聽」不受影響
- 每類句子有自己的語氣指示（帶路、可惜、驚訝、新的一站、最後一站），只給錄音用
- **泡泡的「這站」改成「這一站」**：Gemini 念這句時幾乎每次都自己加上「一」，口語本來也比較順，所以改字配合聲音，字和聲音才一致
- **數字照念法寫給 Gemini**：「1 塊」常被念錯，送去錄音的文字把塊、堆前面的數字寫成國字（一塊、兩塊）；畫面上照舊是阿拉伯數字

## 影響

- 多 60 段錄音，約 0.8 MB，跟著離線包下載
- 改了泡泡的文字、終點名字、積木名字，或積木數的上限，要跑 `pnpm voice`；漏跑的話單元測試會失敗

## 替代方案

- **西薩的家的泡泡也念**：擺飾和西薩的名字約 126 個，乘上「跳進院子了」「貼好了」「收起來了」幾種說法，要錄好幾百句、離線包多約 8 MB，先不做
- **把名字和句尾分開錄再接起來**：生成式語音每段的語氣不同，接起來不自然
- **沒錄到的用裝置語音念**：同一個角色兩種聲音，比不念更奇怪
- **每次都念**：放錯時一直聽到同一句，像在被唸
