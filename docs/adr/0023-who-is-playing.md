# ADR-0023：誰在玩——依年齡調整幫忙的多寡

- 狀態：已採用
- 日期：2026-10-19

## 背景

遊戲一開始是為 5 歲孩子做的（ADR-0008）：主要按鈕旁的手指、卡住時搖動的提示貝都出現得很快。大一點的孩子和大人也會玩，這些提示對他們反而是干擾（#7）。

## 決策

- **三段年齡**，內容集中在 `src/content/age.ts`

  | | 主要按鈕的手指 | 卡住時提示貝搖 |
  | --- | --- | --- |
  | 3–5 歲 | 閒置 4.5 秒 | 25 秒 |
  | 6–8 歲 | 閒置 8 秒 | 45 秒 |
  | 9 歲以上、大人 | 不出現 | 不搖 |

- **第一次回到地圖時問一次**「誰要來玩？」：三張圖卡是由小到大的西薩，請大人選。開場故事結束後會直接進第一關，所以新玩家是在第一次回到地圖時被問；舊存檔下次打開也會被問一次
- 還沒選之前照 3–5 歲的方式幫忙，跟以前一樣
- 第一關的拖曳示範是教學，不分年齡都會出現
- **大人設定**：在「聲音設定」裡，**按住 1.5 秒**才打得開，按鈕會從左邊填滿；孩子隨手點不會跑進去。鍵盤直接按 Enter 就能開。之後的休息提醒、進度備份也放在這裡
- 問年齡的彈窗把焦點放在標題上，三張卡一開始都不會被框起來，免得看起來像已經選好

## 影響

- 存檔多了 `age`（`null` 表示還沒問）
- `useIdle` 可以傳 `null`，表示永遠不提示
- e2e 的共用前置預設「3–5 歲」，其他測試不會被問年齡擋住；要測「被問」的測試先設 `window.keepAgeUnset`
- 彈窗共用的 `Sheet`、`Switch` 搬到 `src/modals/Sheet.tsx`；大人那邊的元件在 `src/modals/Family.tsx`，動作在 `src/game/family.ts`
