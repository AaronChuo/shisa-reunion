# ADR-0031：每區三張插畫明信片，玩出來的收藏

- 狀態：已採用
- 日期：2026-10-30

## 背景

明信片原本每個地方一張（[ADR-0011](0011-place-postcards.md)），用 Wikimedia Commons 的照片（[ADR-0012](0012-postcard-photo-licensing.md)）。v0.27 新加的六區找不到合適的照片，先借用關卡背景。到一個新地區時明信片就收進圖鑑，之後再玩那一區，就沒有新的東西可以收。

2026-10-24／25 的規劃把明信片和關卡背景分開：

- 每區三張明信片，都是精緻的插畫，畫該區最經典的地標
- 照片不再使用
- 明信片要靠玩來收集，給走完的地區重玩的理由

美術依提示詞頁（14 區 × 3 張，5:3）交付了 42 張。

## 決策

- **每區三張**：照美術交付的編號排，也就是提示詞頁的順序。第一張是該區最具代表性的地標，例如國際通、萬座毛、守禮門
- **怎麼拿到**（`cardsEarned`）
  - 第一張：在該區過第一站
  - 第二、三張：該區第 2、3 次走完全程（`progress.clears` 本來就記次數）
  - 沖繩那張一開始就有
- **到新地區**：第一站開始前先看第一張明信片，但還沒收進圖鑑，上面的格子寫「過第一站」；每趟旅程只出現一次
- **拿到時**：過關卡和旅程完成卡上多一行「收到一張明信片」，附小圖和地標名
- **明信片卡**：大圖、要找的東西、介紹文和「念給我聽」；下面三格是這區的三張，拿到的可以點開切換，沒拿到的寫要怎麼拿。從地圖點圖釘時先顯示最新拿到的那張，一張都還沒拿到就先給看第一張
- **文字**
  - 第一張用原本的分區介紹，旁白不用重錄
  - 第二、三張各寫一段新的短介紹，共 28 段，具體的年份、數字都查證過，旁白都錄好了
  - 每張都有自己的兩三個「找找看」，對照插畫裡真的畫得到的東西
- **圖鑑**：明信片頁每個地方一排三格（沖繩一格），寬螢幕兩個地方並排，共 43 張
- **圖檔**
  - 美術交付的 PNG 放 `.cache/postcards/<分區>/<1–3>.png`（不進 repo）
  - `pnpm postcards` 裁成 5:3，輸出 960×576 的大圖和 320×192 的圖鑑小圖，WebP 品質 70
  - 42 張共約 6 MB，跟著 PWA 預先快取
- **照片拿掉**：`photos.json`、`pnpm photos`、照片來源列表和 LICENSE 裡的照片條目都拿掉，「素材來源」只留原創插畫和語音的說明
  - 沖繩那張改用遊戲裡原本畫好的島鏈地圖；其他各區畫的 SVG 只是照片載不到時的替代，一起拿掉
  - 插畫載不到時，改顯示沖繩地圖
- **美術的小修正**：美國村第一張招牌上有幾個像字母的筆畫，用招牌本身的藍色蓋掉
- **舊存檔**：以前打開過明信片的地區（`place:<分區>` 在 `seen` 裡），第一張算已經拿到；走完過 2、3 次的地區，直接拿到第二、三張

## 替代方案

- **三張都一進地區就給**：少了重玩的理由，和原本的規劃不合
- **第二、三張改成撿星星或過特定關卡才給**：要加新的機制和存檔欄位；「走完幾次」本來就有記錄，孩子也看得懂
- **每張明信片都用分區介紹**：三張說的一樣，念起來重複，也對不上畫的地標
- **保留照片當第四張**：照片的畫風和插畫差很多，授權標示也要一直維護

## 影響

- 明信片從 15 張變 43 張，大部分要重玩才拿得到
- 斷網包多了約 5 MB（照片少了約 0.8 MB），預先快取共約 16 MB
- 不再用任何第三方圖片，LICENSE 的第三方素材只剩字型、傳統旋律和 npm 套件
- 單元測試多了明信片數量、每張的介紹長度與圖檔、拿到明信片的規則；e2e 改成「過第一站才收進圖鑑」「第 2 次走完拿到第二張」「地圖圖釘先顯示最新的一張、可以切換」
