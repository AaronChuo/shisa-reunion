# ADR-0017：第 7 台扭蛋機「離島系列」

- 狀態：已採用
- 日期：2026-10-19

## 背景

v0.15 加了宮古島、久米島等離島分區，但扭蛋還是六個系列 50 隻。沖繩的離島各有很有特色的文化和自然，適合做成一個系列，讓孩子去過的地方在圖鑑裡也找得到。

## 決策

- **第 7 台扭蛋機「離島系列」10 隻**，每隻一個島、一個特色，故事 50–75 字，事實逐條查證（宮古島市、竹富町、文化遺產資料庫、琉球新報沖繩事典等）

  | 西薩 | 島 | 特色 |
  | --- | --- | --- |
  | 宮古上布西薩 | 宮古島 | 苧麻織成、薄得像蟬翼，用木槌敲出光澤；國家重要無形文化財 |
  | 久米島紬西薩 | 久米島 | 植物和泥巴染的有光澤深咖啡色絲布，據說是日本紬的源頭；2004 年製作技術成為重要無形文化財 |
  | 大東島西薩 | 南大東島、北大東島 | 本島東邊約 360 公里，四周是峭壁，坐吊籠讓起重機吊上岸；種甘蔗 |
  | 與那國馬西薩 | 與那國島 | 小型在來馬，1969 年成為與那國町的天然紀念物 |
  | 慶良間鹿西薩 | 慶良間群島 | 會游泳到別的島的小鹿，國家天然紀念物 |
  | 伊江島百合西薩 | 伊江島 | 北邊海邊公園的鐵砲百合與百合祭、尖尖的城山 |
  | 泥巴神西薩 | 宮古島島尻 | 「巴恩圖（パーントゥ）」把泥巴抹在大家身上，趕走壞運氣 |
  | 水牛車西薩 | 由布島 | 坐水牛車走過約 400 公尺的淺海 |
  | 神之島西薩 | 久高島 | 傳說阿摩美久最先降臨的地方 |
  | 南十字星西薩（稀有） | 波照間島 | 日本最南邊的有人島，十二月到六月有機會看到南十字星 |

  題材避開已有的西薩：五四花紋的敏沙織已經是八重山西薩，所以改用大東島
- **新頭飾**：鹿角、百合花、水牛角、吊籠
- **屋頂**：海上的小島，有椰子樹、燈塔和渡輪；稀有款南十字星西薩坐在島上
- **系列按鈕**：7 個按鈕改成每排 4 個（手機上數量放在名字下面），兩排就放得下，不會讓「離島」單獨一排把扭蛋機往下推

## 影響

- 扭蛋共七個系列 60 隻
- 沿用一定抽到新的公平規則；離島機台一開始有 10 顆
- 故事事實的出處記在查證紀錄裡；有爭議的說法寫得概括（例如阿摩美久不寫性別、不寫從哪裡來）
