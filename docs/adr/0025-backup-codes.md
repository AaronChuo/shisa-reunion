# ADR-0025：進度備份碼

- 狀態：已採用
- 日期：2026-10-20

## 背景

進度只存在那台裝置的瀏覽器儲存（ADR-0003）。清掉網站資料、換裝置，或 iPhone、iPad 刪掉主畫面圖示再加回來，收集的西薩就全沒了。而要讓主畫面圖示換成新名字「西薩搭搭路」（ADR-0019），偏偏就得刪掉重加（#9）。

## 決策

- **備份碼**：`SHISA1-<進度的 JSON，base64url>-<檢查碼>`（`src/state/backup.ts`）
  - 在大人設定的「備份進度」裡，可以複製，或存成文字檔 `西薩搭搭路備份-YYYYMMDD.txt`
  - 檢查碼是內容的雜湊：少複製一段、改到一個字，都會被擋下來
  - 貼上時多出的空白、換行自動略過
- **還原**：在新裝置的「還原進度」貼上備份碼，或選備份檔
  - 先顯示「備份裡」和「這台裝置現在」各收集幾隻西薩、幾枚福氣幣、走完過幾區，大人按「用備份取代」才取代
  - 還原時經過和讀舊存檔一樣的修正（`normalizeProgress`），所以舊版的備份也讀得進來，不認得的西薩、分區會被拿掉
  - 還原後回到地圖
- **不做雲端備份**：要帳號和伺服器，Vercel Hobby 又限非商業；備份碼不需要後端，先這樣
- 備份碼的文字框是遊戲裡唯一可以選取文字的地方（v0.20.1 起其他地方都關掉了）

## 影響

- 進度在裝置之間搬家、或刪掉主畫面圖示重加之前，都可以先備份
- 備份碼含正在進行的旅程，所以內容比較長（約 2–5 KB），適合複製貼上或存檔，不適合手打
